## 6. 问题清单与修复建议

### 6.1 高优先级问题（P0）

#### P0-1：前端未实现内存二次筛选

**问题描述：**
- 当前实现：所有筛选条件都传递给后端，每次筛选都发起HTTP请求
- 架构要求：后端仅处理日期筛选，其他筛选在前端内存过滤

**影响：**
- 性能下降：每次筛选都有网络延迟（50-200ms vs <5ms）
- 服务器压力：频繁请求增加数据库负载
- 违背架构原则：破坏了"极简后端+灵活前端"的设计理念

**修复方案：**
```javascript
// DepartmentReport.vue 修改建议

// 1. 添加 rawData 缓存
const rawData = ref([])  // 后端返回的完整数据（已按日期过滤）
const tableData = ref([])  // 当前页显示的数据

// 2. 修改 handleQuery：首次加载时获取全部数据
async function handleQuery(queryParams) {
  loading.value = true
  try {
    const requestData = {
      reportCode: activeReportCode.value,
      params: {
        orderDate: queryParams.orderDate,  // 仅传递日期参数
        pageNum: 1,
        pageSize: 10000  // 获取足够多的数据用于前端筛选
      }
    }
    
    const res = await executeReport(requestData)
    
    if (res.code === 200) {
      rawData.value = res.data.rows  // 缓存原始数据
      applyFrontendFilters()  // 应用前端筛选
    }
  } finally {
    loading.value = false
  }
}

// 3. 新增前端筛选函数
function applyFrontendFilters() {
  let filtered = rawData.value
  
  // 应用用户输入的筛选条件（从 ReportFilter 组件获取）
  const filters = filterRef.value?.getFilterValues() || {}
  
  // 客户名称筛选
  if (filters.customerName) {
    filtered = filtered.filter(row => 
      row.customerName?.includes(filters.customerName)
    )
  }
  
  // 订单金额筛选
  if (filters.minAmount) {
    filtered = filtered.filter(row => 
      row.total_amount >= filters.minAmount
    )
  }
  if (filters.maxAmount) {
    filtered = filtered.filter(row => 
      row.total_amount <= filters.maxAmount
    )
  }
  
  // 单据状态筛选
  if (filters.documentStatus) {
    filtered = filtered.filter(row => 
      row.document_status === filters.documentStatus
    )
  }
  
  // 更新总数
  total.value = filtered.length
  
  // 分页
  const start = (pageNum.value - 1) * pageSize.value
  const end = start + pageSize.value
  tableData.value = filtered.slice(start, end)
}

// 4. 监听筛选条件变化
watch(() => filterRef.value?.getFilterValues(), () => {
  pageNum.value = 1  // 重置页码
  applyFrontendFilters()
}, { deep: true })
```

**工作量估算：**
